## 問字

中文模式下以問字鍵 `u` 開頭，再用拼音輸入問題：

- `usangemushishenmezi`（三個木是什麼字）
- `umumumu`（報部件）
- `ufaguoshoudu`（短事實問答）

停頓後雲端返回答字或簡短答案，帶雲朵與帶聲調的讀音（森 sēn），數字鍵選中上屏。

`?` 預設只是問號。在「偏好設定 → 快捷鍵」勾選「沒在輸入拼音時敲 ? 也進入問字」後，未輸入拼音時輸入 `?` 再接拼音同樣進入問字，
中英文模式下均可用。雙拼下 `u` 是音節鍵，問字改用 `Shift`+`U` 再接拼音。此時輸入 `?` 之後接的不是字母時，它還原為普通問號輸出（中文模式遵循「預設中文標點」設定，英文模式使用半形）：
`Space`、`Enter` 只輸出問號本身；逗號等標點跟在問號之後正常輸出；`Backspace` 刪除它。

未開啟雲聯想時同樣可進入問字，但不會得到答案，`Enter` 輸出原文。

## 翻譯選中的文字

在應用中選中一段文字（500 字以內），按 `⌃⌥T`（Windows：`Ctrl + Alt + T`）：

- 選區以漢字為主時譯為學習語言；假名或拉丁字母不少於漢字時譯回中文。
- 候選視窗先顯示「翻譯中…」，譯文返回後作為唯一候選顯示。
- `Enter` / `Space` / `1` 用譯文替換選區；`Esc` 保留原文；其他鍵放棄翻譯並正常交給應用。

雲聯想關閉、密碼框、應用不支援讀取選區（部分 Electron 應用）時，快捷鍵原樣交給應用。快捷鍵在「偏好設定 → 快捷鍵」可修改；
Windows 上修改後需切換到其他輸入法再切回青簡（或重啟應用）才生效。
