## 進入英文模式

- **macOS**：`Caps Lock` 亮起為英文模式，熄滅回到中文。
  想讓 `Caps Lock` 像系統拼音那樣在青簡與「ABC」之間切換輸入法，在「系統設定 → 鍵盤 → 文本輸入 → 編輯」裡開啟用 Caps Lock 切換「ABC」的選項：
  輕按 `Caps Lock` 切換輸入法，按住仍是大寫鎖定；這時青簡自己的英文模式就用不到了。
- **Windows**：單擊 `Shift`（按下即鬆開，不與其他鍵組合）在中 / 英之間切換，工作列右下同步顯示「中」或「英」，Caps Lock 亮著時顯示「A」。
  反向同樣有效：點選工作列的「中 / 英」圖示，青簡隨之切換（懸浮狀態條一併更新）。
  中英模式**所有應用共用一份**：在一個應用裡切到英文，切到別的應用、新開啟的應用也是英文（與搜狗輸入法一致）。
  右鍵這個圖示彈出選單：切中文 / 英文、全形標點、顯示或隱藏懸浮狀態條、開啟設定。
  `Caps Lock` 在 Windows 上只控制大小寫：亮起時無論中英模式均直接輸出大寫英文字母（與微軟拼音一致）。英文模式下 `Shift` + 字母也直接輸出大寫；
  中文模式下 `Shift` + 字母預設是臨時打英文：拼音先上屏，這個大寫字母原樣交給應用；「設定 → 通用」可改成進拼音緩衝區參與匹配（見[按鍵](../getting-started/keys.md)）。

### 改掉或關掉中 / 英切換（Windows）

打字時誤觸 `Shift` 會切到英文、打斷輸入，可以在「設定 → 通用」裡調整（配置 `[shortcut] switch_mode`，如 `["shift", "control"]`）。
下面幾個鍵勾上哪個就能用哪個，可以多選：

| 選項 | 行為 |
|---|---|
| 單擊 Shift | 預設勾上，與微軟拼音一致 |
| 單擊 Ctrl | 不容易誤觸；Ctrl 在其他組合鍵裡的作用不受影響 |
| Ctrl + Alt + Space | 組合鍵，最不容易誤觸 |

一個都不勾時鍵盤不再切中英，只能用工作列 / 懸浮狀態條上的「中」「英」按鈕。
`Ctrl + Space` 不在其中：它是 Windows 自帶的「輸入法/非輸入法切換」，青簡跟著它切中英（與微軟拼音一致），不用勾、一直可用。
裝了英文鍵盤或別的輸入法時，Windows 可能改用它直接切到別的輸入法，這由系統決定；不想要這條系統熱鍵，到「設定 → 時間和語言 → 輸入 → 進階鍵盤設定 → 輸入語言熱鍵」把它改成「未分配」。

如果習慣中英文用兩個不同的輸入法，可以關掉整個**內建英文模式**（同一頁，配置 `[general] english_mode`）：
關掉後青簡固定中文，切換鍵與狀態列按鈕都不再切到英文，需要英文時用 `Win + Space` 切到別的輸入法；
語言欄上的「中 / 英」圖示也不再出現。

兩項都是**改完立刻生效**：輸入法程序會盯著配置檔案，變更後一秒內重新讀取。

## 懸浮狀態條（Windows）

工作列的「中 / 英」不易察覺時，可另開一條**桌面上的懸浮狀態條**：「設定 → 候選視窗」開啟「懸浮狀態條」。它有三格：

| 格 | 顯示 | 點選 |
| --- | --- | --- |
| `中` / `注` / `英` | 當前模式（選了大千注音時顯示「注」；雙拼、五筆這類非全拼方案顯示為「中 · 小鶴雙拼」） | 切換中 / 英，與單擊切換鍵相同；關掉內建英文模式後這一格固定「中」，點了也不切 |
| `，。` / `,.` | 當前模式下標點是否轉為全形。中英各記一份，預設中文全形、英文半形，切換模式時隨之切換 | 切換當前模式的全形 / 半形 |
| ⚙ | | 開啟設定 |

按住拖動可移到螢幕任意位置，位置會被記住；外觀隨系統的深淺色與縮放。
它只在當前輸入法為青簡時顯示：切換到微軟拼音等其他輸入法時收起，切回後再次出現；關閉某個應用不影響它。它與工作列圖示並存。
前臺是全屏應用（遊戲、全屏看影片、演示）時自動收起，退出全屏後回來。也可以在工作列「中 / 英」圖示的右鍵選單裡隨時顯示或隱藏它。

## 行為

英文模式下輸入字母時，候選視窗給出英文詞的補全與拼寫糾正：`recieve` → receive，`seperate` → separate。
字母預設小寫，按住 `Shift` 輸出大寫。

選詞與中文模式一致：`Space` 選高亮候選（詞上屏後空格照常輸入），數字鍵選當前頁第 N 個（沒有第 N 個時數字接進單詞，如 `foo1`），翻頁鍵翻頁，`↑` / `↓` 移動高亮，`Tab` 同樣選高亮項。
**`Enter` 與標點將所敲字母原樣上屏**：`kubectl` 這類詞表中沒有的詞按 `Enter` 即可原樣輸出；沒有候選時 `Space` 也原樣上屏。
帶數字的識別符號（`mp3`、`utf8`）先按 `Enter` 輸出字母再敲數字；沒有候選時數字直接接在字母后。

標點在 macOS 上一律半形；Windows 上預設半形，需要全形時見上文懸浮狀態條。

## 記住使用者的詞

按 `Enter` 原樣上屏過的英文詞（如 `gist`、`python`）會記入個人詞表，下次輸入時排在首位。選過的英文候選同樣記錄。

中文模式下 `key`、`id` 這類末尾落單一個字母、既像英文詞又可讀成拼音的輸入，若常選中文詞（如「客一」「以的」），中文詞排在前面，英文詞退後；
勾選「中文候選排在英文詞前面」後中文詞一律在前。

## 關閉

- 全域性：「偏好設定 → 通用」（Windows：「設定 → 通用」）取消「英文模式給候選」。關閉後為純直通，與未使用輸入法時一致。
- 按應用：預設只在瀏覽器、聊天和文件類應用中給候選，例如 Safari、Chrome、Edge、Firefox、微信、QQ、企業微信、釘釘、飛書、Word、WPS、記事本、備忘錄、Obsidian。
  其他應用中英文模式為純直通，字母原樣交給應用：終端與程式碼編輯器裡不會遮擋應用自身的補全或佔用 `Tab` 鍵，
  Windows 上 Photoshop、Illustrator、SolidWorks、Blender 這類軟體的單鍵快捷鍵（如 Photoshop 的 `W` `H` `V`）也能直接使用。
  「通用」頁的「只在瀏覽器、聊天和文件類應用裡給」控制此名單，取消勾選即處處都給。需要增減具體應用時，在「進階」頁開啟配置檔案，修改其中 apps 一段，每一項均附說明。

## 與中文模式的關係

中文模式下整段輸入為英文詞時同樣直接給出英文候選（`hello` 先英文再拼音，勾選「中文候選排在英文詞前面」後英文排第二），拼音不成立時還會補全字首（`compa` → company）；取消勾選「輸入拼音時也給英文詞和補全」後中文模式只出中文。
無需切換到英文模式，見 [快捷輸入](shortcuts.md)。
