## 中英切換

- **macOS**：`Caps Lock`（鍵盤上的中 / 英鍵），熄滅為中文，亮起為英文。
- **Windows**：單擊 `Shift`（按下即鬆開，不與其他鍵組合），工作列右下同步顯示「中」或「英」，Caps Lock 亮著時顯示「A」；點選該圖示同樣可以切換。
  Windows 上的 `Caps Lock` 只控制大小寫。

英文模式下的行為見 [英文模式](../input/english-mode.md)。

## 候選視窗

輸入拼音時，候選視窗顯示在游標下方：頂部一行是已輸入的拼音（自動按音節分隔），其下是候選，右下角是頁碼。預設豎排，每頁 9 個，均可在設定中修改。
候選右側字號較小、顏色較淺的一列是譯詞，見 [譯詞與生詞](../learning/translation.md)。

## 整句輸入

無需切換模式，連續輸入整句後再上屏：`jintiantianqihenhao` 的首選即為「今天天氣很好」。簡拼同樣可用：`jttqhh`。
兩三個字母的簡拼通常仍按詞處理（`sj` 時間），需要整句時請多輸入幾個音節。

## 常用按鍵

| 操作 | 按鍵 |
|---|---|
| 上屏首選（或高亮候選） | `Space` |
| 上屏第 N 個候選 | 數字 `1` 至 `9` |
| 將拼音字母原樣上屏 | `Enter` |
| 翻頁 | `[` `]`，或 `PageUp` / `PageDown` |
| 移動高亮 | `↑` / `↓` |
| 刪除一個字母 | `Backspace` |
| 清空 | `Esc` |

完整按鍵表（兩個平臺並列）見 [按鍵與快捷鍵](keys.md)。

## 中文標點

未輸入拼音時，中文模式下輸入 `, . ? ! : ; ( ) [ ] < > \ ^ _ $ ~` 得到全形標點，`"` `'` 成對切換；數字之後的 `.` 保持半形（`3.14`）。
輸入拼音時敲標點，預設進英文直輸段，整段原樣上屏。勾選「設定 → 通用」的「組句中標點先上屏候選」（配置 `[general] punct_commits = true`）後，
會轉全形的標點（`,` `.` `?` `!` 等，翻頁鍵除外）先把高亮候選上屏、再接該全形標點：`nihao,` 一氣打完「你好，」；組過拼音後數字後的 `.` 也轉全形，只有緊跟數字的 `.` 保持半形。
`'` 是隔音符（`xi'an`）；不會轉全形的符號（`-` `/` `@`）進入英文直輸，見 [快捷輸入](../input/shortcuts.md#中英混輸)。

Windows 上可關閉全形轉換：「設定 → 通用」的「中文模式標點轉全形」，或點選懸浮狀態條上的「，。」格。英文模式另有一份設定，預設半形；需要全形時在英文模式下點選該格，或開啟「英文模式標點轉全形」。

## 選錯了詞

上屏後用 `Backspace` 刪除，再輸入同一段拼音改選其他候選，上一次記錄的學習會被撤銷；誤按 `Space` 選中錯詞不會被輸入法記住。
連續刪除後面幾個詞再從頭重輸同樣有效：刪除「沃德書」後重輸為「我的書」，「沃德」那次選擇視為未發生。

一段拼音分幾次選完（先選一個字，剩餘部分整句上屏），第二次以同樣方式輸入時，合起來的詞會被記為使用者詞，此後整段輸入直接排在第一位。
