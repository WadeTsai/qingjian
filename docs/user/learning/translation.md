## 譯詞

每個候選右側最多一條譯詞，附詞性。語言由「偏好設定 → 通用」的學習語言決定，英語、日語、西班牙語或越南語，一次只有一種；
選「不顯示譯文」則候選旁不出譯詞，生詞標記與釋義兜底也停，翻譯選中的文字仍可用（譯成英語）。

- 英語：`開發` → v. develop · v. exploit。
- 日語按漢欄位標註平假名：`開發` → v. 開発(かいはつ)する。
- 西班牙語：`開發` → v. desarrollar。
- 越南語：`開發` → v. phát triển。

沒有譯詞的候選留空，不顯示佔位符。隨包釋義表覆蓋整個詞庫；開啟 [雲聯想](../cloud/index.md) 後，表中沒有的詞在輸出後會自動補充一條。

## 生詞

**橙色的譯詞為生詞**：它在上屏時出現在候選視窗中的次數不足三次。達到三次後自動恢復灰色，不加圖示、不彈出提示。
只按上屏那一刻螢幕上的那一頁計算，逐鍵重新整理時短暫出現的不計。

## 直接輸出譯詞

輸入拼音時，不選候選本身，而是輸出其旁邊的譯詞：

| 操作 | macOS | Windows |
|---|---|---|
| 上屏第 N 個候選的第一條譯詞 | `⌥ + 1` 至 `9` | `Ctrl + 1` 至 `9` |
| 上屏第二條譯詞（候選右側有兩條時；日文不帶注音） | `⇧⌥ + 1` 至 `9` | `Ctrl + Shift + 1` 至 `9` |

也可以直接用滑鼠點候選右側的譯詞，點哪條上屏哪條（青簡渲染器）。學習記錄與選中該候選相同。候選沒有對應譯詞時按鍵無效。

## 刪除不需要的候選

輸入拼音時按 `⇧ + 數字`（Windows：`Shift + 數字`）刪除當前頁第 N 個候選：
使用者自造的詞、雲端選過的詞整個刪除；詞庫中的詞不刪除，但清除對它的全部學習記錄，恢復原始排序。
刪除後拼音行下方短暫顯示結果（「已刪除使用者詞「…」」，或詞庫詞無學習記錄時的「沒什麼可刪」），輸入下一個鍵即消失。

## 翻譯選中的文字

按 `⌃⌥T`（Windows：`Ctrl + Alt + T`）將應用中選中的文字翻譯為學習語言，需開啟雲聯想，見 [問字與翻譯](../cloud/question-and-translate.md)。

## 修改快捷鍵

上述三組修飾鍵與翻譯快捷鍵均在「偏好設定 → 快捷鍵」（Windows：「設定 → 快捷鍵」）錄製修改。
macOS 上應避開 `⌃ + 數字`（系統切換桌面）與 `⌘ + 數字`（應用切換標籤頁）；Windows 上 `Alt + 數字` 會被應用作為選單快捷鍵截獲，因此預設使用 `Ctrl`。
全部按鍵見 [按鍵與快捷鍵](../getting-started/keys.md)。

## 學習方式

- 選過的詞、同一段拼音下選過的詞、連續輸入的詞序列，均在本機記錄，整句轉換與排序據此調整。
- 連續選出的兩個詞合起來不在詞庫中且選擇次數達到閾值時，自動記為一個詞。
- 全部在本機，不上傳。檔案位置與清除方式見 [資料與日誌](../help/data-and-logs.md)。
