## 兩種糾錯

- **拼音無法完整切分時**（多輸、少輸、顛倒、輸錯一個字母）：`nihooma` → 你好嗎，`woxiagnqu` → 我想去，`mingtain` → 明天。
  拼音行將被改動的字母以刪除線標出並保留原位，候選全部按糾正後的拼音給出。
  相鄰兩鍵顛倒時不必等整個詞輸完：`mignt`、`migntia` 就已按 `ming't`、`ming'tia` 給出 明天，繼續輸入即可；
  兩種糾正都說得通時優先按顛倒解釋（`mignti` → 命題，而不是改一個字母的 面體）。
- **每個音節合法、整句不通順時**：`meiganxi` 同樣可出「沒關係」（`gan` 視為 `guan`）。此類糾錯隻影響整句，不影響單個詞的候選。

只有糾正後的句子明顯比原樣通順時才糾正；合法的簡拼（`nhao`、`womend`）不會被誤糾，整段為英文詞的輸入（`hello`）也不糾正。

## 不需要糾正時

`Enter` 仍將所敲字母原樣上屏。原樣上屏過一次的字母串，此後不再糾正。

## 記憶習慣性錯誤

被接受的糾正會被記錄：習慣將 `shuo` 輸成 `shou` 的使用者，幾次之後「我說」會自然排到前面。用 `Backspace` 刪除後改選會一併撤銷該記錄。

雙拼下不啟用拼寫糾錯：輸錯一個鍵改變的是整個聲母或韻母，單處編輯的模型不適用。五筆（形碼）下同樣不啟用——敲的是字根編碼，不是拼音。
