翻頁找詞很費事。輔碼是在拼音之後補充幾個字母，把候選範圍直接縮小到想要的詞。

輔碼預設關閉：在配置檔案 `[aux_code]` 分節裡把 `enabled` 改為 `true` 開啟。開啟但沒有可用碼錶（尚未匯入、或全被關掉）時，觸發鍵不生效，`;` 仍按原有行為工作。

## 用法

先按平常的方式輸入拼音，再按觸發鍵（預設 `;`）進入輔碼狀態：此時候選不變，拼音行末尾多一個 `;`。
接著輸入碼錶裡的碼字母，候選隨每多一個字母即時收窄，剩下的詞就是碼以所輸字母開頭的詞。

例如碼錶裡「開發」的碼是 `kf`，輸入 `kaifa` 後按 `;` 再輸入 `kf`，候選只剩「開發」。

- 碼只篩詞，不改變拼音的輸入方式，也不影響整句轉換。
- 碼錶未收錄的詞在輔碼狀態下不顯示。把碼刪空後仍停留在輔碼狀態，候選全部回來；再按一次退格才退出輔碼（配置 `[general] aux_code_keep_empty` 改為 `false` 可回到刪空即退出）。
- 碼不需要敲滿：敲到候選合適即可按空格或數字上屏。
- `Backspace` 刪除碼的最後一個字母，刪空後仍停留在輔碼狀態，再按一次才退出；`Esc` 直接清掉碼。
- 配置 `[general] shift_letter = "compose"` 時，輔碼狀態裡輸入大寫字母等同於先按 `Esc`：清掉碼回到拼音狀態，字母照常參與組句。
- 輔碼狀態下選擇過的詞同樣會被記住，下次純拼音輸入它會更靠前。

## 觸發鍵

預設為 `;`，在「設定 → 輔碼」中修改。可改為 `/` 或反引號等單個可見字元。

雙拼的微軟方案與搜狗方案用 `;` 表示韻母 ing：拼音末尾有落單的聲母時，`;` 作為拼音使用（`x;` 得到 xing），其他情況下才是觸發鍵。

## 碼錶

碼錶需自行匯入：「設定 → 輔碼 → 匯入碼錶…」，接受 Rime 的 `.dict.yaml` 與現成的 `.qj`。
匯入完成後顯示讀入條數、有碼條數、無碼條數與跳過條數。隨包只提供筆畫表，第三方碼錶由使用者自行取得。

匯入的碼錶列在「設定 → 輔碼」頁中，可單獨開關或移除。

### 檔案格式

最小的一份 `my.dict.yaml`（正文每行是「詞 + 製表符 + 碼」）：

```yaml
---
name: 我的碼錶
version: "1"
...

開發	kf
開放	kf
鶴	hn
```

- 碼只用小寫字母 a–z；同一個詞寫多行就有多條碼，碼列裡也可用空格分隔多個碼。
- 頭部 `---` 到 `...` 之間可寫 `name`（碼錶列表裡顯示的名字）、`version`、`columns` 列名與 `import_tables` 合表；沒有頭、直接每行「詞 + 製表符 + 碼」的純文本也接受。
- 形碼碼錶（如小鶴形）由使用者從其官方渠道取得，按上述格式整理後匯入。

## 候選上顯示碼

開啟「設定 → 輔碼 → 候選上顯示碼」後，碼用方括號緊跟在候選詞後面顯示，例如 `鶴[rbm] crane`。不進輔碼也能看：純拼音打字時候選就帶著每個詞的碼（首條），方便邊打邊記；進了輔碼顯示的則是命中當前輸入的那條碼。
