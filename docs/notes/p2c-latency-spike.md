# 神經 P2C 的延遲 spike（2026-09-20）

## 為什麼先量這個

考慮把架構從「詞庫召回 + n-gram 排序 + 神經重排」換成「帶噪拼音 → 神經 P2C 直接生成漢字候選」，
詞庫降級為專名 / 使用者詞 / fallback。換不換的第一道門檻不是準確率而是延遲：

重排慢了只是候選順序晚一點變，候選本身一直在；**P2C 當主候選，候選的存在本身就依賴模型**，模型慢了就沒候選。
而且拼音字首每敲一鍵就變，整句要重解碼一次。所以先量清楚一次重解碼要多久，贏不了這一關，準確率再高也進不了殼。

## 怎麼量的

`crates/qingjian-neural/examples/p2c_bench.rs`。拿現有的字級模型（現位於 `data/models/hanzhang-zhiwei`，full-small 23M，字表 19147，上下文 128）
當代理，跑真正的 beam search：前文進 KV 快取，逐字推進，每步把 `beam × vocab` 個延長取回 CPU 挑 top-k，再按 beam 順序重排快取。

**偏差說明**：現有模型不帶拼音條件，P2C 真模型會多一路拼音編碼。但每鍵增量那一檔（下表）說明拼音字首是可快取的、成本可以忽略，
解碼的成本主導項——beam 條併成一批逐字推進的前向——與條件從哪來無關，所以量級成立。真模型若改層數 / 寬度，按比例縮放即可。

環境：M1 mac，`--features metal` 為 Apple GPU（f16），不帶 feature 為 CPU（candle 自帶 gemm，f32）。
Windows 端是 CPU 推理，參考 CPU 那一列。每檔熱身 3 次、取 10 到 30 次的中位數與 p95。

## 成本拆解（前文 64 字，中位數）

| | beam 4 / 8 字 | beam 8 / 16 字 | beam 8 / 24 字 |
|---|---|---|---|
| Metal：只前向 | 56.8 | 145.9 | 221.6 |
| Metal：+ 取回 CPU | 61.4 | 160.5 | 245.4 |
| Metal：完整（挑 top-k + 重排快取） | 74.9 | 222.4 | 342.4 |
| CPU：只前向 | 137.7 | 329.4 | 502.8 |
| CPU：+ 取回 CPU | 137.7 | 330.0 | 507.1 |
| CPU：完整 | 141.0 | 344.6 | 520.6 |

**前向是絕對瓶頸**：Metal 上佔 66%，CPU 上佔 95%。把 top-k 搬上 GPU 最多省掉 Metal 那 28%
（beam 8 / 16 字 222 → 160 ms），救不了量級。降延遲只能動模型本身：更淺 / 更窄、更小的 beam、更短的解碼長度。

## 結論

1. **P2C 做不了同步主候選。** 使用者打字 5 到 8 鍵每秒（間隔 125 到 200 ms），而 beam 8 / 前文 64 / 16 字一次重解碼
   Metal 要 218 ms、CPU 要 416 ms。每鍵重來一次的話，候選永遠追不上手速。
2. **放進現有的非同步槽位是可行的**，但要挑配置。現在殼是停鍵 80 ms 觸發重排，重排 16 到 34 ms，約 100 到 120 ms 出結果。
   P2C 換進去：Metal beam 4 / 8 字是 80 + 68 = 148 ms，勉強；beam 8 / 16 字是 80 + 218 = 298 ms，明顯能感覺到。
   CPU 端同樣配置要 80 + 207 = 287 ms 與 80 + 416 = 496 ms，Windows 上基本只剩最小那一檔能用。
3. **前文要計費。** 前文 64 字讓解碼成本翻倍（Metal beam 8 / 16 字：90 → 218 ms）。整句評測集上前文值 1 到 2 個點，
   P2C 裡要重新算這筆賬。
4. **因此 P2C 不該當架構替換，該當第二來源**：詞庫出同步候選保住手感與標註（詞性 / 譯文 / 等級），
   P2C 在停鍵後補 OOV 與糾錯。這條路線下上面這些延遲都落在可接受區間。

## 復現

```bash
cargo run --release -p qingjian-neural --example p2c_bench --features metal -- data/models/hanzhang-zhiwei   # Apple GPU
cargo run --release -p qingjian-neural --example p2c_bench -- data/models/hanzhang-zhiwei                    # CPU
```

換模型就換最後那個引數（`.qjm` 單檔案或三件套目錄都認）。表格格式固定，以後訓出真 P2C 模型跑同一條命令直接對比。
