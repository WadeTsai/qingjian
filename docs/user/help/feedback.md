也可以加 QQ 群 [902314603](https://qm.qq.com/q/jBvn2gGTxm)（青簡輸入法使用者內測體驗交流群）直接交流。

## 反饋時請提供

1. 「偏好設定 → 關於 → 複製診斷資訊」：版本、系統、載入的資料、配置原文、日誌目錄，寫入剪貼簿。API 金鑰會被抹去。
2. 執行日誌：點「關於 → 打包日誌到桌面」，把生成的 zip 發來即可（含日誌與配置檔案，不含金鑰）。也可自取：
   - macOS：「關於 → 開啟日誌目錄」，「~/Library/Logs/Qingjian/」下的「qingjian.log.日期」；
   - Windows：「%LOCALAPPDATA%\Qingjian\logs」，含引擎、各應用內的輸入法部分、設定程式三份日誌。
3. 出現問題時所在的應用、輸入的內容、預期結果與實際結果。

可復現時，先開啟「進階 → 詳細日誌」再復現一次，日誌中即有逐鍵記錄；排查完成後請關閉。

## 常見情況

- **安裝後輸入法列表中沒有青簡**：macOS 到「系統設定 → 鍵盤 → 輸入法 → 編輯 → +」在簡體中文下新增，仍沒有則登出後重新登入；
  Windows 登出後重新登入。重啟後仍然沒有，請[提交 issue](https://github.com/qingjian-team/qingjian/issues/new/choose)並附系統版本與安裝方式。
- **開始選單、工作列搜尋框、「設定」中候選視窗被壓在下面**（Windows）：這類系統介面層級高於普通視窗，青簡靠 Windows 的 uiAccess 機制把候選視窗抬到它們之上，
  而系統只對裝在 `C:\Program Files`（`%ProgramFiles%`）裡的程式啟用它，裝到其他目錄或其他盤會靜默失效。請解除安裝後重裝到預設目錄。測試版沒有正式程式碼簽名，同樣會失效，將在簽名版中解決；兩種情況上屏本身都正常。
- **裝了新版輸入法後行為沒變**（Windows）：輸入法 DLL 會被裝進每個程式的程序，**裝新版之前就開著的程式要重啟**才會用上新程式碼——在其中切走輸入法再切回沒有用（模組已經載入進程序了）；資源管理器同理，重啟後任務欄搜尋框才生效。
  只改設定項不受此影響：儲存後一秒內熱載入，不用重啟應用。
- **按 Ctrl + Space 切到了別的輸入法**（Windows）：Ctrl + Space 是系統的「輸入法/非輸入法切換」，只裝了青簡時它切中英（與微軟拼音一致），
  裝了英文鍵盤或別的輸入法時 Windows 可能改用它切換輸入法，這由系統決定。青簡自己的切換鍵在「設定 → 通用」裡勾選（單擊 Shift / 單擊 Ctrl / Ctrl + Alt + Space）；不想要系統這條熱鍵，到「設定 → 時間和語言 → 輸入 → 進階鍵盤設定 → 輸入語言熱鍵」把它改成「未分配」。
- **某個應用中無法切換到青簡或輸入無反應**（Windows）：登出後重新登入，或重啟該應用。
- **騰訊軟體管理、電腦管家等安全軟體中無法輸入**（Windows）：這類軟體帶有程序自我保護（反注入），會阻止第三方輸入法載入進它自己的程序；青簡與其他第三方輸入法（系統自帶的微軟拼音除外）在其搜尋框內都無法輸入、也無法切換中英。這是該軟體的安全機制，輸入法一側無法修復。
- **打字時什麼都不顯示——拼音不出現、候選窗也沒有**（Windows）：多半是後臺服務程序 `qingjian-server` 沒在跑（崩潰 / 被殺 / 裝完沒重啟）。
  輸入法連不上它時會**自己把它拉起來**，下一鍵即恢復；若仍無反應，從開始選單啟動「青簡 Server」，或登出後重新登入。
- **候選視窗遮擋了終端 / 編輯器自身的補全**：英文模式預設只在瀏覽器、聊天和文件類應用中給候選，這些應用裡不出；被遮擋的是中文候選時，切換到英文模式即可。
- **Photoshop 等軟體的單鍵快捷鍵（`W` `H` `V`）沒反應**（Windows）：切換到英文模式即可，英文模式下字母原樣交給這類應用。
- **登入後當前輸入法不是青簡**（macOS）：已知問題，手動切換一次即可，待簽名版解決。
- **懸浮狀態條不見了**（Windows）：它只在當前輸入法為青簡時顯示；確認「設定 → 候選視窗」中的開關已開啟。它每次顯示時都會被移回螢幕可見範圍內，不會停留在螢幕之外。
- **配置檔案改錯**：macOS 輸入法選單會增加一條灰色的錯誤說明，此時沿用上一份可用的配置；按說明改回並儲存即可。
- **某個應用中表現異常**（拼音渲染異常、按鍵被吞、無法讀取選區）：請將應用名稱與現象反饋給作者；可先在「候選視窗」頁更換拼音顯示位置作為臨時處理。
