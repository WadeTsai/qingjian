青簡是一個拼音輸入法。輸入時，候選詞旁邊附帶一條所學語言的譯詞，在輸入的同時記住一個詞。
它首先是一個完整的輸入法：整句輸入、簡拼、拼寫糾錯、模糊音、雙拼、英文模式，全部在本機完成，不上傳資料。

macOS 版與 Windows 版均為測試版，兩個平臺功能相同，按鍵按各自系統的習慣設計，見 [按鍵與快捷鍵](getting-started/keys.md)。Linux 版剛起步，使用 Fcitx5 預設候選面板，見 [Linux](getting-started/linux.md)。

## 從哪裡開始

- 尚未安裝：[安裝](getting-started/install.md)。
- 已安裝：[第一次輸入](getting-started/first-input.md)，介紹中英切換、選詞、翻頁與選錯後的退回。
- 查某個鍵的作用：[按鍵與快捷鍵](getting-started/keys.md)，兩個平臺並列。
- 候選旁的譯詞、橙色的含義：[譯詞與生詞](learning/translation.md)。
- 聯網補全整句、答字、翻譯選中文字：[雲聯想](cloud/index.md)，預設關閉，需自行填寫 AI 服務商。
- 青簡在本機儲存了哪些檔案：[資料與日誌](help/data-and-logs.md)。

## 三條原則

- **輸入優先。** 任何為學習功能增加的延遲、彈窗與干擾都視為設計錯誤。
- **一次只學一種語言。** 一個候選旁只有一條譯詞，不同時顯示英語、日語、韓語。
- **全部在本機。** 拼音轉換、詞庫、學習、釋義均不聯網；雲聯想是可選的補充，資料傳送給使用者自行填寫的服務商，不經過青簡。
