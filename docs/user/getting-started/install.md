## macOS

**系統要求**：macOS 13 或更新。Apple Silicon 與 Intel 各有一個安裝包；不確定機型時，點左上角  → 「關於本機」，檢視「晶片」一行。

1. 下載 `qingjian-<版本>-macos-arm64.pkg`（Apple Silicon）或 `qingjian-<版本>-macos-x86_64.pkg`（Intel），雙擊安裝，需要管理員密碼。
2. 測試版尚無 Apple 開發者簽名，首次開啟會被系統攔截：到「系統設定 → 隱私與安全性」，在底部點「仍要開啟」，再安裝一次。
3. 安裝完成後，輸入法選單中出現「青簡」。

若未出現，到「系統設定 → 鍵盤 → 輸入法 → 編輯 → +」，在「簡體中文」下新增「青簡」；仍未出現則登出後重新登入。

安裝後：

- 選單欄右上出現「中 / 英」狀態項，點選可開啟輸入法選單與偏好設定。
- 偏好設定在輸入法選單中，修改即時生效，沒有「儲存」按鈕。
- 首次使用先到「偏好設定 → 通用」選擇學習語言（英語 / 日語 / 西班牙語），候選旁的譯詞即為該語言。

## Windows

**系統要求**：64 位 Windows 10（1809 或更新）或 Windows 11。安裝包自帶設定介面所需的執行時，不必另裝元件。

1. 下載 `qingjian-<版本>-windows-x86_64-setup.exe`，雙擊安裝，需要管理員許可權。安裝目錄保持預設的 `C:\Program Files\Qingjian`，不要改到其他目錄或其他盤：候選視窗要蓋過開始選單、工作列搜尋這類系統介面，靠的是 Windows 的 uiAccess 機制，系統只對裝在 `%ProgramFiles%` 裡的程式啟用它，裝到別處會靜默失效。
2. 測試版尚無正式的程式碼簽名，SmartScreen 會攔截：點「更多資訊 → 仍要執行」。
3. 安裝完成後，青簡出現在輸入法列表中（工作列右下的「中 / 英」或「拼」處，或按 `Win + Space` 切換），位於「中文(簡體)」之下；系統裝了「中文(台灣)」語言的，在它下面還有一個「青簡」。安裝程式的介面按系統語言顯示簡體或繁體。

**繁體中文（台灣）系統**：青簡同時登記在「中文(台灣)」語言下，名字顯示為「青簡」。若輸入法列表裡沒有自動出現，到「設定 → 時間和語言 → 語言和區域 → 中文(台灣) → 語言選項 → 新增鍵盤」選「青簡」。在它下面打拼音直接出繁體候選，不必開啟「繁體輸出」開關；同一臺機器上「中文(簡體)」下的「青簡」仍出簡體。兩者共用設定、學習資料與統計。

安裝後：

- 工作列右下顯示當前為「中」或「英」；桌面上可另開一條懸浮狀態條，見 [英文模式](../input/english-mode.md#懸浮狀態條（Windows）)。
- 設定在開始選單的「青簡設定」，或懸浮狀態條上的 ⚙。修改即時生效，沒有「儲存」按鈕。
- 首次使用先到「設定 → 通用」選擇學習語言（英語 / 日語 / 西班牙語）。
- **升級後，已經開啟的程式要重啟才會用上新版輸入法**：輸入法 DLL 會被裝進每個程式的程序，在裡面切走輸入法再切回**沒有用**；資源管理器重啟後，工作列搜尋框才算新的。
  只改設定項不受此影響——儲存後一秒內生效，不用重啟應用。

若某個程式中無法切換到青簡，登出後重新登入，或重啟該程式。

**已知問題**：測試版沒有正式的程式碼簽名，在開始選單、工作列搜尋框、「設定」等系統應用中，候選視窗可能被應用遮擋而不可見；輸入與上屏不受影響。此問題將在簽名版中解決。裝錯目錄也會出現同樣現象，見 [遇到問題](../help/feedback.md#常見情況)。

## 升級與解除安裝

升級時直接安裝新版安裝包，學習資料與設定均保留。解除安裝見 [解除安裝](../help/uninstall.md)。
