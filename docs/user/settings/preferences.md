- **macOS**：從輸入法選單開啟（選單欄「中 / 英」狀態項，或系統輸入源選單中青簡的幾項），名為「偏好設定」。
- **Windows**：開始選單的「青簡設定」，或懸浮狀態條上的 ⚙，名為「設定」。

常規設定修改即時生效；自定義短語的啟用開關即時生效，新增或編輯在點選「儲存規則」後生效。

### 繁體輸出

開啟「繁體輸出」後，候選與上屏文字按 OpenCC 轉成繁體（只換字形，不換用語：軟體 → 軟體）。雲端詞與整句補全同樣轉換。引擎內部仍按簡體處理：使用者詞、詞頻、輸入統計與輸入日誌都記簡體，譯詞照常顯示。

Windows 上青簡還登記在系統的「中文(台灣)」語言下（「青簡」與「青簡注音」兩個）：在它們下面打字時不看這個開關、始終輸出繁體；「中文(簡體)」下的「青簡」才按開關來。開關開啟則三處都出繁體。「青簡注音」同樣不看「拼音方案」：在它下面始終是大千注音，「中文(簡體)」與「中文(台灣)」下的「青簡」才按這裡選的方案來。

## 橫排與拼音位置

橫排時候選排成一行，僅高亮候選在下方單獨一行顯示譯詞，頁碼在行尾。
macOS 上可以把這一行展開成多行：先在「候選視窗」頁的排佈下面勾選「橫排時 ↑ / ↓ 展開成多行」（預設不勾，不勾時橫排下的按鍵與以前一樣：
`↑` / `↓` 逐個移動高亮，`←` / `→` 移動拼音游標，`Esc` 清空）。勾選後立即生效：
按 `↑` / `↓` 會把這一行展開成 6 行的矩陣（一行對應一頁候選），同時換到上一行或下一行；`←` / `→` 改為在候選之間移動（沒展開時也是，拼音游標改用 `⌥ + ←` / `⌥ + →`），
數字鍵選的是高亮所在那一行的第幾個，高亮移出矩陣上下邊緣時按行滾動，翻頁鍵一次翻一屏。展開後窗口大小在這一輪輸入裡保持不變；超過四個字的候選在格子裡截斷顯示為「…」，
高亮到它時矩陣下方給出完整內容。繼續輸入拼音或按 `Esc` 收回單行。
「只在視窗」顯示拼音適用於終端與部分 Electron 應用，這類應用對行內拼音的渲染效果較差。

## 輸入法選單（macOS）

雲聯想開關、模糊音子選單、偏好設定、開啟日誌目錄、版本號。配置檔案解析失敗時增加一條灰色的錯誤說明，此時沿用上一份可用的配置，輸入法不退出。

## 直接修改配置檔案

全部設定儲存在一個配置檔案中，「進階」頁有「在編輯器中開啟配置檔案」，檔案內每一項均附說明。儲存後一秒內生效，無需重新切換輸入法。

## 自定義短語（macOS）

「自定義短語」頁以常駐表格顯示啟用狀態、內容和固定候選位置，可直接勾選啟用或停用。點選「+」新增，雙擊已有行或點選「編輯…」修改，選中後點擊「−」刪除。新增或編輯時，填寫 1–32 個小寫英文字母的輸入碼、1–9 的候選位置和文本，點選「儲存規則」。文本可以包含空格、換行、地址、長回覆或標點，按原樣輸出；候選視窗只展示長文本的簡短預覽。

例如將 `ee` 的第 1 位設定為 `：`，第 2 位設定為 `；`，輸入 `ee` 後按空格選擇首項，按 2 選擇第二項。普通拼音候選填入其他位置，學習與模型重排不會改變自定義位置；雲端詞只使用不影響固定位置的剩餘格。若固定位置超過第一頁容量（例如第 9 位、每頁 5 項），本次查詢不顯示雲端詞。位置跨頁時按當前頁的序號選擇。

同一個輸入碼的位置不能重複，新增和編輯衝突時提示並拒絕儲存；停用規則也保留其位置。沒有足夠普通候選時保留空位，空位不能上屏。選擇已有規則後可編輯、停用或刪除。

編輯期間若規則被其他視窗或外部檔案修改，儲存會提示並保留草稿，不覆蓋新規則。儲存會保留現有短語條目的註釋。

預設中文標點模式會儲存，重啟後仍生效；選擇半形不會改變自定義短語中的全形標點。英文模式不觸發自定義短語。

### 系統的文本替換

「自定義短語」頁勾選「也使用系統設定『鍵盤 → 文本替換』裡的條目」（預設勾選）後，系統文本替換中的條目在輸入拼音時同樣可用：
輸入碼敲全後短語出現在該輸入碼最靠前的空位（頁裡的規則優先佔位），`Space` 或數字鍵上屏。
只有輸入碼全為小寫英文字母的條目可用；系統設定中新增或修改的條目在下次切換到青簡時生效。它們不在頁裡的表格中列出，要改請到系統設定。
