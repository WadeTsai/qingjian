## 日期、時間、算式

| 輸入 | 結果 |
|---|---|
| `rq` / `sj` / `xq` | 當天日期（`2026年9月3日`、`2026-09-03`）、當前時間（`19:06`、`19點06分`）、星期，插在首選之後 |
| `v1+2` | 算式：出 `3` 與 `1+2=3`，支援 `+ - * / ^`、括號、小數 |
| `v123` | 中文數字：一百二十三 與 壹佰貳拾叄；金額：一百二十三元整 與 壹佰貳拾叄元整 |
| `v123.5` | 小數讀法：一百二十三點五 與 壹佰貳拾叄點伍；金額：一百二十三元五角 與 壹佰貳拾叄元伍角（小數最多兩位，到分） |
| `u4e00` | 按十六進位制碼點輸入字元：一；`u+1f600` 出 😀 |

以 `v` 開頭後，數字與運算子均進入算式，不再用於選詞或翻頁；選第二項用 `↑` / `↓` 加 `Space`，`Enter` 將所敲內容原樣輸出。
以 `v` 開頭的英文詞（`very`）不受影響，仍給出英文候選。

`v` 與 `u` 兩個字首鍵可在「偏好設定 → 快捷鍵」修改，只能是 v、u、i 三個字母（它們不作為任何拼音的開頭）。
雙拼下 `v` / `u` 是音節鍵，改用 `Shift`+`V` / `Shift`+`U` 開頭（`V1+2`、`U4e00`）。

`u` 之後接拼音為 [問字](../cloud/question-and-translate.md)，需開啟雲聯想；`?` 預設只是問號，可在「快捷鍵」頁勾選讓它也進入問字。

## 中英混輸

中文模式下無需切換：

- 整段輸入為英文詞時直接給出英文候選。拼音不成立時（`hello` 只能切成 `he l l o`）英文排第一，拼音成立時（`china`）英文排第二。
  勾選「偏好設定 → 通用」的「輸入拼音時中文候選排在英文詞前面」後英文固定排第二（`hello` 先 荷蘭咯 再 hello，`key` 先 可以 再 key），
  `Space` 上屏的仍是中文，按 `2` 選英文；沒有中文候選時（`github`）英文仍排第一。
  專名按正確大小寫上屏：`windows` → **Windows**，`github` → **GitHub**，`python` → **Python**。
- 拼音不成立且不少於 3 個字母時補全字首：`compa` → company / companies / compared。
- 不想在中文模式裡看到英文詞與補全，取消勾選「偏好設定 → 通用」的「輸入拼音時也給英文詞和補全」（配置檔案裡是 `[general] english_in_chinese = false`），英文模式不受影響。
- 一句拼音末尾接一個英文詞時，整句直接包含該詞：`woxiangxuehaorust` → 我想學好rust，`wodeid` → 我的ID，`woyongvim` → 我用vim，`yongwindows` → 用Windows。
  拼音行顯示 `wo'xiang'xue'hao'rust`，`Space` 上屏整句。該英文詞需在詞表中（使用者自己輸入過的也算，見 [英文模式](english-mode.md)）。
  `database` 這類同時可讀作拼音的輸入，按兩種讀法的通順程度排序：我的database 排第一、我的大塔巴瑟 排第二；
  `womenqubeijing` 只給出 我們去北京。`fan`、`to` 這類短詞按拼音處理；可糾正為通順拼音的輸入錯誤（`shiide` → 是的）不視為英文。
  英文詞只識別句末，`wozaidebugzhege` 這類位於句中的暫不支援（可先上屏前面的中文，再打英文詞）。
- **中英混雜詞**（字母 + 漢字）直接按「字母 + 拼音」打：`cpan` → C盤，`bzhan` → B站，`dpan` → D盤，`txu` → T恤，`agu` → A股，`xguang` → X光。
  隨身碟 因 `u` 是問字字首，打 `youpan`（與 優盤 同讀音，隨身碟 排前）。它們也能進整句：`wozaibzhan` → 我在B站。
- 輸入拼音時輸入不會轉全形的符號（`-` `/` `@`，翻頁鍵除外）即進入**英文直輸**：`no-way` 整段原樣顯示，之後的字元原樣追加，
  `Space` / `Enter` 原樣上屏（空格字元也一併輸出），因此中文模式下可直接輸入 `no-way` 這類帶符號的串。
- 會轉全形的標點（`,` `.` `?` `!` `:` 等）預設也進直輸段。勾選「設定 → 通用」的「組句中標點先上屏候選」（配置 `[general] punct_commits = true`）後，
  它們不再進直輸段，而是先把高亮候選上屏、再接該標點（`nihao,` 一氣打完「你好，」）。
  要在候選後面接半形標點，先切英文模式（Windows 也可關閉「中文模式標點轉全形」）。

## emoji

前幾個候選中有對應 emoji 的詞，emoji 緊隨該詞之後，右側標註對應的詞：`ku` → 哭 😢 😭，英文模式 `smile` → smile 🙂 😊。
每個詞最多兩個，一次最多三個，上屏不記錄學習。
不需要的話關掉「偏好設定 → 通用」的「候選後面顯示 emoji」（配置檔案裡是 `[general] emoji = false`）。
