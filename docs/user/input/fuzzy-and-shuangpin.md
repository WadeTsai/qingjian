## 模糊音

九條：z/zh、c/ch、s/sh、n/l、f/h、l/r、an/ang、en/eng、in/ing。預設全部關閉。

開啟：輸入法選單「模糊音」子選單勾選，或「偏好設定 → 模糊音」。開啟 z/zh 後輸入 `zi` 也出 知 / 之，開啟 f/h 後輸入 `kaiha` 也出 開發。
輸入正確的詞仍然優先，模糊匹配的詞排在其後。韻母三條只對完整音節生效。

## 輸入方案

「偏好設定 → 通用」裡是**兩個獨立的設定**：

| 設定 | 可選 |
| --- | --- |
| 拼音方案 | 全拼（預設）、小鶴雙拼、自然碼、微軟雙拼、搜狗雙拼、智能ABC、小浪雙拼、首道雙拼、注音、關 |
| 注音鍵盤排列 | 標準（大千，預設）、倚天（見下文） |
| 五筆（86 版） | 開 / 關（預設關） |

兩邊可以各自單開，也可以同時開——同時開著就是**混輸**，見下一節。

中英切換始終是 `Shift`，與選哪套方案無關。全拼、雙拼與注音都是「拼音」的讀法，共用同一份詞庫、整句轉換與學習資料；五筆是形碼，走的是另一條路。
兩個都關著時按全拼算，不會一個字都打不出。

Windows 上「中文(台灣)」語言下的「青簡注音」不看這裡的拼音方案、始終是注音（並輸出繁體）；注音使用者直接在輸入法列表裡選它即可。這裡選的方案管「中文(簡體)」與「中文(台灣)」下的「青簡」。

## 注音鍵盤排列

「偏好設定 → 通用 → 注音鍵盤排列」（`[general] zhuyin_layout`）選符號在哪些鍵上，與微軟注音的「鍵盤配置」對應：

| 排列 | 配置寫法 | 特點 |
| --- | --- | --- |
| 標準（大千，預設） | `dachen` | 聲母在左、韻母在右，`1`=ㄅ `q`=ㄆ `a`=ㄇ …；聲調 `6` `3` `4`、輕聲 `7` |
| 倚天 | `eten` | 聲母按拼音字母記（`b`=ㄅ `p`=ㄆ `m`=ㄇ `f`=ㄈ …），`'`=ㄘ、`=`=ㄦ；聲調 `2` `3` `4`、輕聲 `1` |

一聲都是空格。排列同時管「拼音方案」選了注音的情況與 Windows「中文(台灣)」下的「青簡注音」。

## 雙拼

七套方案：小鶴、自然碼、微軟、搜狗、智能ABC、小浪、首道。

- 拼音行顯示解出的全拼（`nihc` → `ni'hao`，小浪 `nihs` → `ni'hao`）。「偏好設定 → 通用」勾上「雙拼在輸入框顯示原始按鍵」後，輸入框裡改為顯示敲的鍵（`kdfa`），候選視窗的拼音行照舊顯示全拼（`kai'fa`）。學習按全拼記錄，切回全拼後同樣受益。
- 零聲母：小鶴 / 自然碼寫 `aa` `ai` `ah`（a、ai、ang）一族；微軟 / 搜狗寫 `o` + 韻母鍵（`oa` `ol` `oh`）；智能ABC 也寫 `o` + 韻母鍵，但韻母鍵按它自己的表（ei 是 `oq` 不是 `oz`），且不認雙寫母音（`aa` 是 zha、`ee` 是 che）；小浪寫 `aa` `ai` `ah` `ao`、`uu`（e）、`ui`（ei）、`un`（en/eng）、`ur`（er）、`oo`（o）、`ou`（ou）。
- 微軟 / 搜狗的 `;` 為 ing：輸入拼音時末尾有落單的聲母，`;` 作為拼音（`x;` → xing）；其他情況下仍為標點。
- 微軟 / 搜狗的 ü 鍵為 `y`：`ny` / `ly` 輸入女 / 綠，`jy` / `qy` / `xy` / `yy` 解為 ju / qu / xu / yu。其他方案也接受各自 ü 鍵與 j / q / x / y 的組合，但同鍵已有的合法讀法優先（微軟 `jv` 仍為 jue，小浪 `jv` 仍為 jing）。
- 智能ABC 翹舌聲母以 `a` 為 zh、`e` 為 ch、`v` 為 sh（`ai` → zhi、`ei` → chi、`vi` → shi）。
- 小浪雙拼翹舌聲母以 `e` 為 zh、`i` 為 ch、`v` 為 sh；`x` 為 ü（`lx` → lv，`nx` → nv，`jx` → ju）；`v` 兼作韻母 uai 與 ing；未在鍵位表列出的韻母按原拼鍵輸入（如 a/e/i/u 及 o 對 uo/o）。
- 首道雙拼翹舌聲母以 `v` 為 zh、`i` 為 ch、`e` 為 sh；零聲母雙寫首字母或照全拼輸入（`aa` `ai` `an` `ao` `oo` `ou` `en` `er`），ang 為 `ay`，e / ei / eng 以 `u` 引導（`ue` `ui` `uf`）；ue 在 `l`（`jl` → jue），üe 單獨在 `b`（`lb` → lve）。
- 雙拼下 v / u / i 均為音節鍵，[快捷輸入](shortcuts.md) 中的算式與問字改為按住 `Shift` 輸入：`Shift`+`V` 後接算式（`V1+2`），`Shift`+`U` 後接拼音或碼點（`U4e00`），與搜狗、微軟雙拼一致。未輸入拼音時才生效；模式鍵改過的，按改後的字母加 `Shift`。
- 全拼輸入 `lue` / `nue` 與詞庫形式 `lve` / `nve` 等價；j / q / x / y 後的 `v` 也認（`tiqv` → 提取，與微軟、搜狗一致）。雙拼統一解為 `lve` / `nve`。
- 「嗯」按習慣用 `en` 輸入（`enen` → 嗯嗯）；全拼下單獨敲 `ng` 也出「嗯」，與其他拼音連寫時請用 `en`。
- 已知限制：`lo` 與 `luo` 同鍵，解為 luo。小浪方案中 `en` 與 `eng` 同碼（`un`），統一解為 `en`；`dia`/`dai` 同碼解為 `dai`，`lia`/`lai` 同碼解為 `lai`，`nen`/`niang` 同碼解為 `niang`。首道方案中 `den`/`dia` 同碼（`dk`），解為 `den`。

## 五筆（形碼）

86 版五筆。敲的是字根編碼而不是讀音：`ggll` 出 一，`khlg` 出 中國，`gant` 出 開發。
候選框頂部原樣顯示敲的編碼，不打亂成音節。

- 編碼打到哪兒算哪兒，按該字首查表。編碼正好打全的詞排在同字首的更長編碼詞前面（這就是一級 / 二級 / 三級簡碼）。
- 空格上屏高亮候選，數字鍵選詞，與拼音一致；候選旁的譯文、詞頻學習與生詞記錄也照常。
- 這條路上沒有拼音的那些能力：整句輸入、簡拼、模糊音、拼寫糾錯，以及 `v` / `u` / `i` 開頭的[快捷輸入](shortcuts.md)。
  這三個鍵在五筆裡是字根鍵，不再當模式鍵。
- 單用五筆時把拼音方案設為「關」；那樣連中英混輸也沒有，敲多長都是編碼。

## 混輸（五筆 + 拼音）

**拼音方案與五筆同時開著**就是這樣。敲字根編碼與敲拼音都認，五筆打不出的字直接打拼音：

```text
gant     → 開發          （編碼）
nihao    → 你好          （編碼查不到，落到拼音）
ggll     → 一            （編碼切不成音節，拼音那半條自動讓位）
woxiangxuehao → 我想學好  （第 5 個字母起五筆已經查不到東西，只剩拼音）
```

- **編碼打全的五筆詞排在最前，其次是拼音候選，只敲了編碼字首的五筆詞排在拼音之後**：`ga` 第一個是 開，`kai` 第一個仍是拼音的 開（編碼以 `kai` 開頭的詞在後面）。
- 五筆編碼最長 4 位，所以**敲到第 5 個字母時自動只剩拼音**，不用手動切。
- 同一個詞兩邊都命中時只出現一次。
- 中英混輸（句末夾英文詞）只在拼音那半條路上，五筆編碼本身不參與。
- 混輸下小寫 `v` / `u` / `i` 是字根鍵，[快捷輸入](shortcuts.md) 的算式與問字同雙拼一樣改為按住 `Shift` 輸入（`V1+2`、`U4e00`）；超過四個字母的輸入只可能是拼音，拼寫糾錯照常。

反過來（主要用拼音、偶爾用五筆）也能用，只是一級 / 二級簡碼（`wo` 是 夥）會排在拼音首選前面——不想要就把五筆關掉。
