## 隨包詞庫

基礎詞庫 8.7 萬條，另有 11 本領域詞庫隨包：法律、醫學、地名、成語、詩詞名句、IT、財經、飲食、動物、汽車、歷史人物。
預設只開啟成語，其餘在「偏好設定 → 詞庫」勾選。領域詞庫隻影響「是否有這個詞」，不改變整句轉換的權重。

## 匯入使用者詞庫

「偏好設定 → 詞庫 → 匯入詞庫…」，接受三種格式：

- 青簡 TSV：每行 `詞<Tab>拼音<Tab>詞頻`，拼音音節間以空格分隔。
- Rime 的 `.dict.yaml`：讀取名稱和檔案內的詞條，詞條須為 `詞<Tab>拼音[<Tab>權重]`，拼音音節間以空格分隔，非整數權重按 1 處理。不支援 `import_tables` 引用的其他詞庫、自定義 `columns` 列順序或 `.schema.yaml` 方案配置。
- 青簡 `.qj`：他人制作的詞庫檔案，自帶名稱與許可證。

TSV 與 Rime 詞庫匯入時，`lue` / `nue` 自動統一為 `lve` / `nve`。詞庫用 `v` 表示 ü。
舊詞庫裡寫成 `lue` / `nue` 的詞也照常能打。

匯入後列在隨包詞庫之下，顯示名稱、條數、許可證。可單獨開關；「移除」只將檔案移到一旁，不刪除。

Windows 匯入時會轉換成 `.qj` 並自動啟用，設定頁顯示匯入條數或失敗原因。沒有可用詞條的檔案不能匯入。
檔案選擇視窗支援按 Ctrl 或 Shift 多選，批次匯入 YAML、TSV 或 `.qj`；單個檔案失敗不影響其餘檔案，完成後顯示成功、失敗數量及各檔案結果。
輸入法執行時通常在約一秒內自動載入；同名重新匯入和移除也會自動更新，無需重啟。
若手動編輯配置時出現格式錯誤，詞庫仍按上次有效的開關設定載入；修正配置後自動恢復應用新設定。
Rime 檔案要經「匯入詞庫…」轉換，直接放進詞庫目錄不會載入。
