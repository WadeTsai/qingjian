青簡不上傳任何資料。拼音轉換、詞庫、學習、釋義全部在本機完成，沒有賬號，沒有統計上報。

## 檢查更新

每天向官網 qingjian.app 讀取一次版本列表（一個靜態檔案），有新版本時在輸入法選單（macOS）、工作列「中 / 英」圖示的右鍵選單（Windows）與設定的「關於」頁提示，不自動下載、不自動安裝。
請求不帶賬號、裝置標識或任何輸入內容，只有 HTTP 請求本身帶的資訊（IP 地址、`qingjian/<版本號>` 的 User-Agent）。
版本列表帶數字簽名，驗證不通過的列表一律忽略。在「關於」頁關掉「自動檢查更新」後不再聯網檢查。

## 本機檔案

- **macOS**：「~/Library/Application Support/Qingjian/」（訪達中按 `⇧⌘G` 輸入此路徑）。
- **Windows**：「%APPDATA%\Qingjian」（在資源管理器位址列中直接輸入此路徑）。

均為純文本，可隨時開啟檢視：

| 檔案 | 內容 | 是否含輸入內容 |
|---|---|---|
| `config.toml` | 配置 | 否 |
| `.env` | 雲服務的金鑰，填寫後才有；僅當前賬戶可讀 | 否 |
| `user.tsv` | 每個詞被選擇的次數 | 選過的詞 |
| `user-words.tsv` | 自動造詞與雲端選中的使用者詞 | 選過的詞 |
| `user-choices.tsv` | 某段拼音下選過的詞 | 拼音與選過的詞 |
| `user-english.tsv` | 原樣上屏過的英文詞 | 英文詞 |
| `user-typos.tsv` | 被接受的輸入錯誤糾正（輸成了什麼、本意是什麼） | 拼音音節 |
| `user-ngram.tsv` | 詞與詞之間的接續 | 連續輸入過的詞 |
| `user-glossary-<語言>.tsv` | 雲端補充的個人釋義 | 詞與譯詞 |
| `user-vocab.tsv` | 每條譯詞被看到 / 上屏 / 輸出的次數 | 譯詞，不含中文；私密輸入不寫入 |
| `usage.tsv` | 按天的漢字 / 詞 / 上屏次數，僅數字 | 否 |
| `update.json` | 上次檢查更新的時間與查到的新版本 | 否 |
| `input-log.jsonl` | 輸入日誌：每次上屏的按鍵、切分、候選、所選序號，以及退格重打、直通的標點、雲端聯想給過什麼、所在應用 | 按鍵與上屏的文字 |
| `dicts/` | 使用者匯入的詞庫 | 否 |
| `themes/` | 自制主題，見[主題](../settings/themes.md) | 否 |
| `codes/` | 使用者匯入的碼錶（「設定 → 輔碼」匯入的，可在那裡開關或移除） | 否 |

這些檔案每次整體替換，即使輸入法中途崩潰也不會留下寫到一半的檔案。

「進階」頁的「學習輸入習慣」關掉後，`user-*.tsv` 這些學習資料不再更新，已有的仍參與排序；要從頭開始就刪掉這幾個檔案。

## 雲聯想發什麼

預設關閉。開啟後，輸入拼音時的拼音、游標前後各幾十個字的上下文、本機給出的候選，會發送給使用者在「雲服務」頁填寫的 AI 服務商。
資料直接從本機發送到服務商，不經過青簡：青簡沒有自己的伺服器。

- 密碼框中不傳送；應用宣告為私密的輸入框（Windows 上輸入範圍為私密 / 密碼 / PIN 的）裡也不傳送。
- 開啟期間，隨包釋義表中沒有譯詞的詞在輸出後單獨傳送一次，只含該詞。
- 關閉「雲服務」頁的開關後不再發送任何請求。

## 輸入日誌

測試版預設開啟。每次上屏在本機記錄一行：按鍵、切分、看到的第一頁候選、所選序號、翻了幾頁、從第一鍵到上屏用了多久、所在應用的標識
（macOS 為 bundle identifier，Windows 為 exe 名）。另有幾類事件各記一行：組句中退格後重打了不同的鍵、組句之外直接打出的標點與回車、
雲端聯想給出的候選與整句、切換應用或點到別處、輸入法啟動。只含通過青簡打出的內容，不含應用中已有的文字，不含密碼框與應用宣告為私密的輸入框中的任何內容，那裡也不學習習慣。
它只儲存在本機，用於離線迴歸評測與個人模型，不會自動傳送給任何人。

- 關閉：「偏好設定 → 進階」取消勾選「記錄輸入日誌」。
- 清空：同一頁的「清空輸入日誌」。
- 測試期間若願意將此檔案提供給作者，對改進排序有很大幫助；完全自願。

## 執行日誌

- **macOS**：「~/Library/Logs/Qingjian/」，檔名「qingjian.log.日期」。
- **Windows**：「%LOCALAPPDATA%\Qingjian\logs」。引擎（「server.日期.log」）、各應用內的輸入法部分（「tsf.日期.log」）與設定程式（「settings.日期.log」）都在這一個目錄；
  「設定 → 關於」或「進階」頁的「打包日誌到桌面」會把整個目錄連同配置檔案打成一個 zip，反饋時發這個檔案即可。

按天分檔案，保留 7 天。預設級別不記錄輸入內容；僅在「進階」頁開啟「詳細日誌」後才逐鍵記錄，用於排查問題，排查完成後請關閉。
