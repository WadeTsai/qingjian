## 挑法

- 只收詞：碎片（是不 / 看一 / 的不 / 而不 / 是是）、了 / 的 結尾的動詞短語（完成了 / 額外的）、動詞 + 到 / 成（切換到 / 壓縮成）、代詞開頭的組合（我把 / 你都）不要。
- 語料 ≥ 20 次的按語料次數寫，與 `dict.tsv` 詞頻同一尺度；不到 20 的輸入法 / 開發術語（上屏 14、模糊音 9、大模型 9、候選框 1、賬套 3）按 20 計，不然排在最後。

## 進語言模型：當 token 統計會傷整句

領域詞是真詞，第一版讓 `bigram` 正常把它們當 token 統計。整句評測集掉 0.1 個點（退步 15 句 / 進步 9 句），退步的全是低頻詞：
詞庫（語料 77 次）當 token 之後，語料裡的 詞 + 庫 都歸了這個 token，二元 (詞, 庫) 的證據沒了，而 77 次的一元又太弱，
`zhuciku` 出 助詞哭、`cikuli` 出 次苦力；長句（43 次）同理出 長局，模糊音 出 莫和隱喻。這正是短語層筆記裡的機制 ①。

改成領域詞也走 `bigram --phrases` 的合成路（`--phrases` 可重複給）：分詞時摘掉、統計完按成分合成一元 / 二元。整句裡它們的得分與原來的兩詞路徑一樣，
詞級多了個能整塊選的詞。兩把尺子都回來了：

## 還留著的兩件事

- 「整段輸入恰好是一個詞時不出整句候選、由詞級排序定」這條規則（`plain_sentence`）在 token 方案下會咬人：行數 輸給 行書、再也 輸給 在也、分詞 輸給 分次。
  走合成路之後冷查詢全回來了（行數 / 再也 / 分詞 / 而是 / 不對 都是首選）：合成的 (上文, 詞) 二元讓詞級得分與原路徑相等，詞級排序與 Viterbi 的判斷一致。不用動引擎。
- 語料只有幾次的術語（上屏 9、長句 39、模糊音 7）語言模型認識但機率低，`shangping` 仍出 上平（上屏 第二）；這是資料如實的結果，選一次個人學習就頂上去，不給它們編次數。
- 語料 0 次的（微軟拼音 / 懸浮條 / 全半形 / 輸入日誌）明顯不是隱私，但按「基礎詞庫只收公開語料裡有的詞」的規矩沒進；要進得另立一個不看語料的白名單。
