兩個平臺功能相同，按鍵按各自系統的習慣設計。表中 `⌥` 為 Option，`⌘` 為 Command，`⌃` 為 Control，`⇧` 為 Shift；
「—」表示該平臺沒有此鍵。

## 切換模式

| 操作 | macOS | Windows |
|---|---|---|
| 中 / 英切換 | `Caps Lock` | 單擊 `Shift`（設定裡還可勾單擊 `Ctrl`、`Ctrl + Alt + Space`，可多選）；系統的 `Ctrl + Space`；或點選工作列 / 懸浮狀態條上的「中 / 英」 |
| 直接輸入大寫英文 | 英文模式下按住 `⇧` | `Caps Lock` 亮起（中英模式均可） |
| 輸入拼音時臨時輸入一個大寫字母 | `⇧ + 字母`：拼音原樣上屏，再輸入該大寫字母；設定裡可改成「進組句」：大寫按小寫參與匹配，`Cpan` 與 `cpan` 一樣能出「C盤」 | 同左 |
| 切換全形 / 半形標點 | 中文全形、英文半形，不可更改 | 點選懸浮狀態條上的「，。」格，中英各記一份 |
| 切換到其他輸入法 | `⌃ + Space`（系統） | `Win + Space`（系統） |

Windows 的「中 / 英切換」鍵在設定裡勾選，可以多選：單擊 `Shift`、單擊 `Ctrl`（打字時容易誤觸 `Shift` 的話）、`Ctrl + Alt + Space`；一個都不勾就只剩按鈕能切。中英模式所有應用共用一份。關掉「內建英文模式」後，切換鍵與工作列、懸浮狀態條上的「中」「英」都不再切到英文，需要英文時用 `Win + Space` 切到別的輸入法。

Windows 的主鍵盤數字和常用標點按當前系統鍵盤佈局識別；非美式佈局的字母、AltGr 和組合音符輸入仍有侷限。

Windows 上中 / 英的切換鍵可以勾選（設定 → 通用，配置 `[shortcut] switch_mode`，可多選）：**單擊 Shift**（預設，與微軟拼音一致）、
**單擊 Ctrl**（Shift 老是誤觸時用）、**Ctrl + Alt + Space**（組合鍵，最不易誤觸）；一個都不勾就只剩工作列 / 懸浮狀態條上的「中」「英」按鈕能切。
改完**立刻生效**；沒在打字時 Shift 在其他組合鍵裡的作用不受影響。系統自帶的 `Ctrl + Space`（輸入法/非輸入法切換）也能切中英，與微軟拼音一致，不在勾選項裡。

還可以整個關掉**內建英文模式**（設定 → 通用，配置 `[general] english_mode`）：關掉後青簡固定中文模式，
切換鍵與工作列、懸浮狀態條上的按鈕都不再切到英文，需要英文時用 `Win + Space` 切到別的輸入法。
詳見 [英文模式](../input/english-mode.md)。

## 輸入組句時（拼音 / 注音 / 五筆）

微軟 / 搜狗雙拼用 `y` 輸入 ü：`ny` / `ly` 對應女 / 綠，`jy` / `qy` / `xy` / `yy` 對應 ju / qu / xu / yu；原來的 `ju` / `qu` / `xu` / `yu` 也可繼續使用。各方案說明見 [模糊音與輸入方案](../input/fuzzy-and-shuangpin.md)。

| 操作 | macOS | Windows |
|---|---|---|
| 上屏高亮候選（無候選時上屏所敲的拼音 / 注音 / 編碼） | `Space` | `Space` |
| 上屏當前頁第 N 個 | `1` 至 `9` | `1` 至 `9` |
| 用滑鼠上屏（青簡渲染器） | 點候選上屏它；點候選右側的譯詞上屏那一條譯詞 | 同左 |
| 將敲的字母 / 注音符號原樣上屏 | `Enter` | `Enter` |
| 上屏高亮候選並接全形標點 | 組句中的 `,` `.` `?` `!` 等會轉全形的標點（翻頁鍵除外；需勾選「組句中標點先上屏候選」，`[general] punct_commits`，預設關）；`'` 是隔音符，`-` `/` `@` 等不轉的符號進英文直輸 | 同左 |
| 刪除游標前一個字母 / 注音 / 編碼 | `Backspace` | `Backspace` |
| 刪除游標後一個字母 | `Delete` | — |
| 刪除游標前一個音節（五筆下是整段編碼，同左的「全部」） | `⌥ + Backspace` | — |
| 刪除游標前全部拼音 | `⌘ + Backspace` | — |
| 清空 | `Esc`（開啟「橫排時 ↑ / ↓ 展開成多行」且矩陣展開著時，第一下先收回單行） | `Esc` |
| 清除輔碼（保留拼音與候選） | `Esc` | `Esc` |
| 移動高亮（到頁邊自動翻頁） | `↑` / `↓` | `↑` / `↓` |
| 橫排展開成 6 行矩陣並換行（macOS，需先在「偏好設定 → 候選視窗」勾選「橫排時 ↑ / ↓ 展開成多行」，預設關） | `↑` / `↓`；`←` / `→` 在候選之間移動（單行、展開後都是），移出矩陣上下邊緣時按行滾動 | — |
| 翻頁 | `[` `]`、`PageUp` / `PageDown`、`⇧ + Tab`（上一頁） | `[` `]`、`PageUp` / `PageDown`、`Shift + Tab`（上一頁） |
| 進入輔碼狀態並輸入碼 | `;`（可改為其他單個可見字元），之後直接輸入碼字母 | 同左 |
| 接受雲端整句補全 | `Tab`；無補全時翻頁 | `Tab`；無補全時下一頁 |
| 移動拼音游標 | `←` / `→`（開啟橫排展開開關後，橫排下這兩個鍵改為移動候選高亮，拼音游標用 `⌥ + ←` / `⌥ + →`） | `←` / `→` |
| 按音節移動游標 | `⌥ + ←` / `⌥ + →` | — |
| 游標移到開頭 / 末尾 | `⌘ + ←` / `⌘ + →`，或 `Home` / `End` | `Home` / `End` |

游標停在中間時，候選只按游標之前的拼音計算（`ni|hao` 出 你）；上屏後其餘拼音保留，游標移到末尾。
若前面某個音節輸入有誤，macOS 上可按 `⌥ + ←` 移到其後、`⌥ + Backspace` 刪除後重輸、`⌘ + →` 回到末尾。

### 注音模式（Windows）

「設定 → 通用」開啟「大千注音」後，組句中的按鍵改為：

| 操作 | Windows |
|---|---|
| 上屏高亮候選 | `Enter` |
| 將注音符號原樣上屏 | `Shift + Enter` |
| 一聲 / 輕聲 | `Space` |
| 聲調與符號（進入組句，不選詞） | 數字鍵，`-` `;` `,` `.` `/` |

大千鍵盤佈局把數字鍵與 `- ; , . /` 都分給了注音符號和聲調，所以注音模式下這些鍵不再選詞，選詞用 `Enter`；`Space` 是一聲。macOS 暫無注音模式。

> **五筆（形碼）**：組句時敲的是字根編碼，沒有音節的概念，所以「刪到音節邊界」「拼音行分段」這些不適用，
> 左右鍵按單個字母移動游標。整句輸入、簡拼、模糊音、拼寫糾錯在五筆下都不生效，
> `v` / `u` / `i` 也不再是模式鍵（它們是字根鍵）。選詞、翻頁、上屏、刪除候選與拼音一致。
> 拼音方案與五筆**同時開著**是混輸：兩邊都出候選、編碼打全的五筆詞在前，見 [模糊音與輸入方案](../input/fuzzy-and-shuangpin.md)。

翻頁鍵對可改為 `,` `.` 或 `-` `=`：「偏好設定 → 快捷鍵」。

## 英文模式下

| 操作 | macOS | Windows |
|---|---|---|
| 選擇高亮候選 | `Space`、`Tab` | `Space`、`Tab` |
| 選擇第 N 個候選（當前頁沒有第 N 個時，數字作為內容接在所敲字母后，如 `gpt6`） | 數字鍵 | 數字鍵 |
| 移動高亮 / 翻頁 | `↑` / `↓`、翻頁鍵 | `↑` / `↓`、翻頁鍵 |
| 原樣輸出所敲字母 | `Enter`、標點 | 同左 |

沒有候選時數字直接接在字母后（`xq1`）；帶數字的識別符號先按 `Enter` 輸出字母再敲數字。

## 譯詞與刪除候選

| 操作 | macOS | Windows |
|---|---|---|
| 上屏第 N 個候選的第一條譯詞 | `⌥ + 數字` | `Ctrl + 數字` |
| 上屏第二條譯詞（候選右側有兩條時） | `⇧⌥ + 數字` | `Ctrl + Shift + 數字` |
| 刪除第 N 個候選 | `⇧ + 數字` | `Shift + 數字` |

僅在輸入拼音時有效。三組修飾鍵在「偏好設定 → 快捷鍵」（Windows：「設定 → 快捷鍵」）錄製修改；
macOS 上應避開 `⌃ + 數字`（系統切換桌面）與 `⌘ + 數字`（應用切換標籤頁），Windows 上 `Alt + 數字` 會被應用作為選單快捷鍵截獲。
刪除候選的說明見 [譯詞與生詞](../learning/translation.md#刪除不需要的候選)。

## 雲聯想

| 操作 | macOS | Windows |
|---|---|---|
| 翻譯應用中選中的文字 | `⌃⌥T` | `Ctrl + Alt + T` |
| 翻譯結果：替換選區 | `Enter` / `Space` / `1` | 同左 |
| 翻譯結果：保留原文 | `Esc` | `Esc` |
| 問字 | 輸入 `u`（雙拼下 `Shift`+`U`）再輸入拼音；勾選「敲 ? 也進入問字」後未輸入拼音時輸入 `?` 再接拼音同樣可用 | 同左 |

均需先開啟雲聯想，見 [問字與翻譯](../cloud/question-and-translate.md)。翻譯快捷鍵可修改；Windows 上修改後需切換到其他輸入法再切回青簡才生效。

## 字首鍵

| 輸入 | 結果 |
|---|---|
| `rq` / `sj` / `xq` | 日期 / 時間 / 星期 |
| `v` + 算式或數字 | 算式結果、中文數字與金額（`v123.5` → 壹佰貳拾叄元伍角）；雙拼下以 `Shift`+`V` 開頭 |
| `u` + 十六進位制 | 該碼點對應的字元；雙拼下以 `Shift`+`U` 開頭 |
| `u` + 拼音 | 問字（需開啟雲聯想）；`?` + 拼音需在「快捷鍵」頁勾選後可用 |

兩個平臺相同，詳見 [快捷輸入](../input/shortcuts.md)。`v` 與 `u` 可在「快捷鍵」頁改為 v、u、i 三者之一。

## Linux（Fcitx5）

單擊 `Shift` 切換中英；按住 `Shift` 輸入字母不會切換。`Space`、`1` 至 `9` 以及候選點選選詞，
全拼 / 雙拼下 `Enter` 原樣輸出，`Backspace` / `Delete` 編輯，`Esc` 取消，方向鍵移動高亮或游標。
`[` / `]` 和 `PageUp` / `PageDown` 翻頁；翻頁鍵可在配置檔案修改。

Linux 的 `Tab` 規則：沒有組句時 `Tab` / `Shift + Tab` 交給應用；中文組句中 `Tab` 接受整句補全，
無補全時下一頁；英文組句中 `Tab` 選擇高亮候選；組句中的 `Shift + Tab` 始終上一頁。
Linux 當前提供本地候選，尚無雲端整句補全。裸問號的既有還原規則優先。

數字選擇當前頁對應候選；當前頁沒有這一格時數字接入緩衝區，`hao6` 回車可原樣輸出。
組句中會轉全形的標點（`,` `.` `?` `!` 等）上屏高亮候選並接全形標點，不可轉的符號（`-` `/` `@`）進入英文直輸段，
進入英文直輸段後數字和標點繼續追加，`gpt-6` 後按空格得到 `gpt-6 `。
英文候選開啟時，數字、翻頁鍵和空格同樣可選詞，空格選詞後保留一個空格。
小鍵盤運算子保持半形；關閉 NumLock 時按導航鍵處理。

`[general] shift_letter = "compose"` 可讓大寫字母參與中文組句，預設原樣輸入大寫英文。
雙拼下 `Shift + V` / `Shift + U` 分別進入表示式 / 碼點輸入，入口字母可在 `[shortcut]` 修改；問字的雲服務暫未提供。
大千注音（`[general] scheme = "zhuyin"`）下，數字及 `- ; , . /` 輸入符號和聲調，空格補一聲，再按空格可選詞；
`Enter` 選高亮，`Shift + Enter` 原樣輸出注音。

Linux 預設 `Alt + 數字` / `Alt + Shift + 數字` 上屏第一 / 第二條譯詞，`Shift + 數字` 刪除候選，
可在配置檔案 `[shortcut]` 修改。安裝與配置位置見 [Linux](linux.md)。
