雲聯想預設關閉。開啟後，輸入拼音時會將當前拼音與游標附近的文字傳送給**使用者自行填寫的** AI 服務商，換回候選詞與整句補全。
資料直接從本機發送到服務商，不經過青簡；密碼框與應用宣告為私密的輸入框中不傳送。

## 開啟

「偏好設定 → 雲服務」：開啟開關，填寫服務地址、模型、API 金鑰。預設為 DeepSeek，任何 OpenAI 相容的服務均可。
金鑰只儲存在本機，不隨配置檔案匯出。選單欄「中 / 英」之後帶 ☁︎ 表示聯想已開啟。
填寫完成後點「測試連線」，將以當前地址、模型、金鑰傳送一條最小請求，結果顯示在視窗底部：成功時顯示模型名與耗時，失敗時顯示原因。
輸入法由系統啟動，不讀取終端中設定的代理；若需通過代理訪問服務商，請在系統設定中設定系統代理，或使用 TUN 模式的代理工具。

傳送的內容：所敲字母、本機的切分、游標前後各幾十個字的上下文、本機給出的候選。詳見 [資料與日誌](../help/data-and-logs.md#雲聯想發什麼)。

## 雲端候選詞

輸入拼音時停頓 300 毫秒後，雲端給出的詞補入候選第一頁**末尾**兩格（「雲服務」頁可調為 0 至 4），帶雲朵標記，數字鍵正常選擇，上屏消耗整段拼音。

- 前面的本地候選位置不變，`Space` 上屏的仍是本地首選。
- 未返回、無結果、超時均不改變顯示，不預留、不畫佔位。
- 選中詞庫中沒有的雲端詞會記為使用者詞（按所敲的讀音記錄，不按雲端給出的讀音），下次本地直接給出。
- 雲端可糾錯：`zhgdoima` 同樣可得到「這個東西嗎」。
- 只敲聲母（簡拼，如 `fhyq`）時雲端不再給詞，只給整句補全——按聲母湊出來的詞大多不是真詞。

## 整句補全

同一次請求還返回一條整句：以當前輸入開頭的完整說法（`suoyiwoxiangq` → 所以我想去吃飯），帶雲朵顯示在拼音右側。
`Tab` 接受，繼續輸入則替換。有應用上下文時接著上下文續寫。

## 譯詞自動補充

隨包釋義表中沒有譯詞的詞，在輸出後會單獨向雲端詢問一次（只發送該詞），返回的譯詞存入本機的個人釋義表，下次候選旁即有顯示。
關閉雲服務後不再發送任何請求。

## 不聯想的情況

上屏之後不聯想；英文模式、以 `v` 開頭的算式不聯想；密碼框中不聯想。
